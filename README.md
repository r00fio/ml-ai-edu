# AI & Machine Learning from Scratch

This repository contains my journey of learning Artificial Intelligence and Machine Learning from the ground up.

The project starts with basic neural network concepts implemented manually in Python and gradually moves towards real-world machine learning tasks using modern frameworks.

## Topics covered

- Perceptron implementation from scratch
- Linear classification
- AND / OR / XOR logic gates using neural networks
- Activation functions
- Forward propagation
- Loss functions
- Gradient descent and optimization
- Neural network training
- Image recognition using MNIST dataset
- Introduction to TensorFlow / Keras

## Goal

The goal of this repository is to understand how AI algorithms work internally by implementing core concepts step by step, rather than only using high-level libraries.

## Technologies

- Python
- NumPy
- TensorFlow / Keras
- Matplotlib
- Jupyter Notebook

## Progress

This repository represents my practical path of learning AI/ML, starting from mathematical foundations and moving toward deep learning applications.
